One identity.
Every catalog.

The HAND Customer Registry is the members’ view of the HAND registry. Search by a name, a HAND ID, or an identifier your catalog already carries, and land on one verified identity, with a crosswalk to the public systems you already use. Now in beta, it comes with HAND membership.

How It Works

One search box.
Three ways in.

Start from whatever you already have. The Customer Registry resolves it to a single identity.

01
A name
Search the way people actually type. Close misspellings still find the right person.
02
A HAND ID
Paste a HAND ID and it resolves to exactly one identity, the same answer every time, for every member.
03
An ID you already hold
Start from an identifier your catalog already carries, from public systems like Wikidata, ISNI, VIAF, or MusicBrainz.
What Members See

One verified identity.
Its public crosswalk.

HAND ID
A persistent identifier
Never reassigned, one click to copy, and resolvable through the global DOI handle system. Names change and catalogs merge; the HAND ID doesn’t.
Known as
Every name on record
The primary name, birth name, and aliases, including transliterations, all pointing to the same person.
Crosswalk
The bridge to your systems
Public identifiers for the same person: the Library of Congress, VIAF, ISNI, Wikidata, MusicBrainz, and public social handles. If your catalog uses any one of them, you can get to the HAND ID, and from the HAND ID to the others.
Status
